# React Hooks Learning — React 18+

Интерактивный справочник по встроенным хукам React: от базовых `useState`/`useEffect` до хуков React 19 (`use`, `useActionState`, `useOptimistic`, `useFormStatus`).

Каждый хук — это отдельное демо с пояснением, зачем он нужен, и работающим примером.

## Запуск

```bash
npm install
npm run dev
```

## Структура

- `src/App.tsx` — список хуков и навигация.
- `src/demos/*.tsx` — интерактивная демонстрация каждого хука.
- `src/App.css` — стили интерфейса.

## Хуки и зачем они нужны

### Базовые

| Хук | Зачем нужен |
| --- | --- |
| `useState` | Локальное состояние компонента. |
| `useEffect` | Побочные эффекты: подписки, запросы, синхронизация с DOM. |
| `useLayoutEffect` | Эффект до отрисовки браузером: измерения, анимации, предотвращение вспышек. |
| `useMemo` | Кэширование дорогих вычислений между рендерами. |
| `useCallback` | Кэширование функций-обработчиков для детей, зависящих от ссылочного равенства. |
| `useRef` | Сохранение мутабельного значения без перерисовки; ссылки на DOM-элементы. |
| `useReducer` | Сложная логика состояния, похожая на Redux. |
| `useContext` | Чтение значений контекста без prop drilling. |
| `useImperativeHandle` | Кастомный API дочернего компонента через ref. |

### React 18

| Хук | Зачем нужен |
| --- | --- |
| `useId` | Стабильные уникальные id для связки label/input и SSR/CSR. |
| `useDeferredValue` | Откладывает «тяжёлую» ветку UI, чтобы приоритетная оставалась отзывчивой. |
| `useTransition` | Помечает обновление как неблокирующее, показывая pending-состояние. |
| `useSyncExternalStore` | Подписка на внешнее хранилище с безопасным SSR/гидратацией. |
| `useInsertionEffect` | Вставка CSS-in-JS до layout-эффектов, чтобы избежать блокировки рендера. |

### React 19

| Хук | Зачем нужен |
| --- | --- |
| `use` | Читает Context или Promise прямо в рендере, упрощая подписки и Suspense. |
| `useActionState` | Управляет состоянием формы/экшена: pending, ошибки, результат. |
| `useOptimistic` | Оптимистичное обновление UI до ответа сервера. |
| `useFormStatus` | Информация о состоянии ближайшей формы из любого её ребёнка. |

## Когда использовать что

- **Производительность форм/списков** → `useDeferredValue`, `useTransition`.
- **Интеграция с внешними хранилищами** → `useSyncExternalStore`.
- **CSS-in-JS** → `useInsertionEffect`.
- **SSR-friendly id** → `useId`.
- **Формы и экшены** → `useActionState`, `useOptimistic`, `useFormStatus`.
- **Suspense + Context/Promise** → `use`.
